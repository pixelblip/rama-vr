# Rama VR

A-Frame flythrough of Clarke’s Rama: a closed 16 × 50 km cylinder for Quest / desktop.

Open `index.html` (or deploy this folder as a static site). No build step.

## Vercel

1. Import this GitHub repo in Vercel.
2. Framework preset: **Other**.
3. Leave build command empty. Output directory: `.`
4. Deploy, then open the HTTPS URL on a Quest browser and tap **Enter VR**.

WebXR needs HTTPS, which Vercel provides.

## Controls

- **Quest:** left stick fly, right stick turn / height, trigger or grip to go faster, **A / X** or stick click for the next camera, **B / Y** for night.
- **Desktop:** click to look, WASD to move, **T** next view, **N** night, **M** mute.
